# Glossario tecnico

Termini che compaiono nei documenti e nelle conversazioni, spiegati con analogie pratiche.
I termini propri di un gioco stanno nel glossario del suo GDD.

| Termine | Significato |
|---|---|
| **Browser** | Il programma per navigare (Chrome, Safari). I nostri giochi girano qui dentro. |
| **Changelog** | Registro delle modifiche, come il giornale dei lavori di cantiere. |
| **Client** | Il dispositivo del giocatore (TV o telefono) che mostra il gioco. |
| **Commit** | Una "fotografia" salvata dei file in un certo momento, con una descrizione. |
| **Git** | Archivio delle versioni: permette di tornare a qualunque fotografia precedente. |
| **HTTPS** | Collegamento cifrato (il lucchetto nella barra). Obbligatorio per microfono e schermo acceso. |
| **Hosting** | Il computer su internet (affittato) dove gira il server del gioco. |
| **JSON** | Formato di testo per dati strutturati, leggibile e modificabile a mano. |
| **Motore (engine)** | Il codice che contiene solo le regole del gioco, come un regolamento applicabile da chiunque. |
| **Node.js** | Il programma che fa funzionare il server scritto in JavaScript/TypeScript. |
| **pnpm / npm** | Programmi che scaricano e gestiscono le "librerie" (pezzi di codice già pronti), come un magazzino di componenti prefabbricati. |
| **PWA** | Sito web che si può "aggiungere alla schermata Home" come un'app, senza store. |
| **QR code** | Il quadratino da inquadrare con la fotocamera per aprire il link della partita. |
| **Seme (seed)** | Numero di partenza della casualità: stesso seme, stesse estrazioni. |
| **Server** | Il computer centrale che fa da arbitro e tiene lo stato vero della partita. |
| **Server autorevole** | Il server decide tutto; i telefoni chiedono, non decidono. |
| **Simulatore / Monte Carlo** | Robot che giocano migliaia di partite per verificare se i numeri sono equilibrati. |
| **Skill / comando rapido** | Una procedura salvata che Claude esegue quando si scrive `/nome`. |
| **Socket.IO / WebSocket** | Un "filo diretto" sempre aperto tra server e dispositivi, per aggiornamenti istantanei. |
| **Stack** | L'insieme delle tecnologie scelte, come i materiali scelti per una costruzione. |
| **Test automatico** | Un piccolo programma che controlla che una regola funzioni, rilanciabile in un secondo. |
| **TypeScript** | JavaScript con "controllo dei tipi": segnala errori prima di eseguire, come un correttore ortografico per il codice. |
| **Tunnel HTTPS** | Ponte sicuro temporaneo che rende raggiungibile dai telefoni un server acceso sul PC. |
| **Vista filtrata** | La parte di dati che un dispositivo è autorizzato a vedere. |
| **WebRTC / SFU** | Tecnologie per l'audio tra browser; la SFU è un "centralino" che smista le voci. |
