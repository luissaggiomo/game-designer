# Decisioni generali

Scelte valide per **tutti i giochi**. Ogni decisione è numerata e non si cancella:
se cambia, se ne aggiunge una nuova che la sostituisce (come le varianti in corso d'opera).

Modello di voce:

```
## DG-NNN — Titolo
- Data: AAAA-MM-GG · Stato: ✅ decisa / 🟡 proposta / ❌ superata da DG-XXX
- Contesto: perché serviva decidere
- Alternative: A) ... B) ...
- Scelta: ... · Motivo: ...
```
