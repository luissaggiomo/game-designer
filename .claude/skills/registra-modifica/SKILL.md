# Registra modifica

1. Ricostruisci cosa è cambiato nella sessione (file modificati, `git diff` se disponibile).
2. `CHANGELOG.md` del gioco: aggiungi le voci sotto la data odierna, nelle categorie
   Design / Aggiunto / Modificato / Corretto / Rimosso. Frasi brevi, comprensibili da un non programmatore.
3. `ROADMAP.md` del gioco: aggiorna gli stati (⬜ 🔄 ✅ ⏸️), la data di aggiornamento e i punti aperti bloccanti.
4. Se il gioco cambia fase: aggiorna anche la tabella in `README.md` principale.
5. Se sono cambiate regole generali del progetto: aggiorna il `CHANGELOG.md` principale.
6. Proponi a Luis il messaggio di commit (`[nome-gioco] descrizione`) e chiedi se procedere.
