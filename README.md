# Game Designer

Laboratorio di giochi di società digitali: TV come tabellone, telefoni come controller,
tutto dal browser. Uso personale.

## Giochi

| # | Gioco | Cartella | Fase | Note |
|---|---|---|---|---|
| 01 | Il Direttivo *(titolo provvisorio)* | [giochi/01-il-direttivo](giochi/01-il-direttivo/) | 1 · Design | Gioco politico-aziendale con spie, 4–8 giocatori |

Le fasi sono descritte in [docs/PROCEDURE.md](docs/PROCEDURE.md).

## Come si avvia un nuovo gioco

In Claude Code scrivere: `/nuovo-gioco` seguito dal nome del gioco.

## Comandi rapidi disponibili

| Comando | A cosa serve |
|---|---|
| `/nuovo-gioco` | Crea la cartella di un nuovo gioco dai modelli |
| `/stato-lavori` | Riepilogo di avanzamento di un gioco (o di tutti) |
| `/verifica` | Esegue test e controlli prima di dichiarare "fatto" |
| `/registra-modifica` | Aggiorna changelog e roadmap dopo un lavoro |
| `/decisione` | Presenta alternative su una scelta e registra la decisione |
